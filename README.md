# うちのレシピ（試作 v0.3）

家族でレシピを共有するためのWebアプリ。`index.html` 1枚で動き、ビルドもNode.jsも不要です。
iPhoneのSafariで開いて「ホーム画面に追加」すると、アプリのように使えます。

## できること

| 機能 | 内容 |
|---|---|
| リンクから追加 | クラシル・デリッシュキッチン・Nadia・クックパッドなどは、写真・材料・作り方を自動で取り込む。YouTubeは概要欄に材料が書いてあれば読み取る |
| 文字の貼り付け | Instagramのキャプション、YouTubeの概要欄、スクショの文字（iPhoneの「テキスト認識表示」でコピー）を材料と作り方に振り分ける |
| 手入力 | 写真は複数枚、手順ごとにも付けられる |
| 手書きメモ | 写真のまま保存し、あとで文字に起こせる |
| 人数換算 | 分数で表示（大さじ1と½）。小さじ3以上は大さじに直す。少々・適量は換算しない。個・枚などで端数が出たら「目安」と表示 |
| 調理モード | 画面が消えない、大きい文字、スワイプで手順送り、「5分」などをタップでタイマー、材料チェック |
| 買い物リスト | 作りたい料理を人数つきで選ぶと材料を合計してまとめる。調味料など家にありそうなものは最初はチェックなし。コピーしてGoogle Keepに貼るか、共有メニューから送る |
| 作った写真 | 「作った！」の記録に自分で作った料理の写真を付けられる。チェックを入れるとレシピの表紙になる。編集画面でも表紙の写真を選び直せる |
| 追加した人 | Dan / Miki から選ぶ（このスマホの持ち主を設定で決めておくと自動で入る） |
| その他 | タグ・検索（料理名・食材）、お気に入り、「作った！」記録、バックアップの書き出し・読み込み |

## 手元で動かす

```bash
python dev_server.py
```

ブラウザで http://localhost:5190 を開きます。
`dev_server.py` は、リンク先のレシピページを代わりに取りに行く中継役も兼ねています。
ブラウザは他のサイトのページを直接読めないためです。

## 今の制限（次の段階で対応）

- **家族との同期はまだありません。** データは開いた端末の中（IndexedDB）にだけ保存されます
- **リンク読み取りは手元のサーバー経由でしか動きません。** 公開後は Supabase Edge Function を同じ中継役として置く予定です
- Instagramはログインの壁があるため、リンクからはほぼ読めません。キャプションのコピペかスクショで追加します

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `dev_server.py` | ローカル確認用サーバーとページ中継 |
| `manifest.webmanifest`, `icon-*.png` | ホーム画面に追加したときの名前とアイコン |
